# GAYA – Boutique d'accessoires

Application web Full-Stack de gestion d'une boutique d'accessoires.

## Fonctionnalités

- Affichage et recherche des accessoires
- Ajout d'accessoires avec image
- Modification et suppression des produits

## Technologies

- **Frontend:** Angular, TypeScript, Bootstrap
- **Backend:** Node.js, Express
- **Base de données:** MongoDB, Mongoose

## Installation

### Backend

```bash
cd backend-accessoires
npm install
npm start
```

### Frontend

```bash
cd frontAccessoires
npm install
npm start
```

Le frontend est accessible sur `http://localhost:4200` et le backend sur `http://localhost:3000`.
